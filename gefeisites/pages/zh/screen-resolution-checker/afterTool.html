怎么测

  1. 把窗口移到目标显示器，浏览器页面缩放恢复 100%，等实时数值稳定。
  2. 比较“报告的屏幕”“布局视口”和“可见视口”。屏幕与视口尺寸使用 CSS 像素，视口描述浏览器内容区域。
  3. 结合“设备像素比”和“估算输出像素”阅读。估算值用报告的屏幕尺寸乘 DPR；系统缩放和页面缩放都会影响 DPR。
  4. 调整窗口、进入全屏或旋转手机，观察视口更新。连同页面缩放和系统缩放一起记录，并对照系统显示设置与显示器菜单。

什么算合格

这里的“合格”是本次目视检查的正常参考，不是厂商验收标准，也不是硬件认证。

  • 数值随窗口或方向变化更新。缩放和浏览器控制栏可能让 CSS 屏幕尺寸或视口偏小，这本身不代表物理像素减少。

结果怎么看

报告尺寸小于面板规格
CSS 像素与系统缩放可以解释差异。例如 4K 输出在 200% 缩放时，可能报告约 1920 × 1080 CSS 像素。
视口小于屏幕尺寸
窗口大小、标签栏、侧栏和系统界面都会占用内容空间。
页面缩放改变 DPR 或估算输出
页面缩放能改变 DPR，因此输出尺寸仍是估算。手指捏合缩放通常主要改变可见视口缩放。
浏览器帧率或颜色缓冲值出乎预期
帧率来自动画回调，不是显示器 Hz。颜色缓冲是浏览器值，不证明面板原生位深。

浏览器 API 不能可靠读取面板物理分辨率、EDID 型号、实际像素密度或真实刷新率。“估算输出像素”来自计算，不是硬件直接测量。

测不出来怎么办

  1. 恢复 100% 页面缩放，把窗口固定在一块显示器上，等数值稳定再比较。
  2. 到系统设置和显示器自身菜单核对实际分辨率与缩放，不只凭估算标签确认物理输出。
  3. 显示“未报告”或“不支持”时可换浏览器。估算帧率时保持标签页可见；API 不可用不代表硬件故障。

分辨率检测常见问题

为什么 4K 屏幕显示 1920×1080？

200% 系统缩放会让浏览器以 CSS 像素报告约 1920×1080，但面板仍可能是 4K。

能检测显示器刷新率吗？

只能估算浏览器动画回调频率，不能把它当作硬件刷新率测量。

网页能识别显示器型号吗？

不能。浏览器出于隐私和兼容性不会公开 EDID 型号信息。
