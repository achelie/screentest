How to test

  1. Show normal moving content for a few minutes, use everyday brightness, and dim the room. Do not use a long static pattern as a repair attempt.
  2. Enter fullscreen and select Solid color cycle. Inspect gray, red, green, blue, white, and black for fixed logos, taskbars, or window outlines.
  3. Choose Low-gray uniformity and compare the actual 5%, 10%, 20%, 30%, and 50% levels. Then inspect Moving color bars and Gradient sweep if useful.
  4. Use Play for changing patterns. Selecting a manual color or gray sample pauses it. Continuous playback stops after five minutes and shows black; a manually paused static sample has no such timer protection, so exit it promptly.
  5. Record any fixed outline and return to ordinary content. Recheck after normal use or rest instead of leaving this pattern up.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • No fixed logo or interface outline appears across several colors and ordinary content. A faint dark-gray band by itself does not establish permanent burn-in.

How to read your result

An outline repeats at the same position across colors
Image retention or uneven wear is possible. A single observation cannot tell whether it is permanent.
Gray shows bands or cloudy areas
Near-black uniformity may vary without a recognizable retained image. Compare the Grayscale test and real content.
The outline fades after ordinary content or rest
That is more consistent with temporary retention. Record how it changes across later checks.

The page cannot measure pixel aging, confirm permanent burn-in in one pass, or determine warranty eligibility. The five-minute stop applies to continuous playback, not paused static inspection.

Allow the display to complete its normal automatic maintenance when it powers down. For a remaining afterimage, use the instructions for your exact model: Sony explains its automatic and manual OLED panel care, Samsung documents monitor Screen Optimization and Pixel Refresh, and LG lists the Pixel Cleaning path by webOS version.

If you cannot get a result

  1. Confirm the mark repeats across multiple colors and real content, then recheck after normal use or rest.
  2. If the pattern is still, choose Play for cycling; manual color or gray selection pauses playback. Finish static inspection promptly because the playback timer is inactive while paused.
  3. Follow the manufacturer's routine maintenance instructions. Do not repeatedly run deep pixel refresh or prolonged static patterns to chase one test image.

OLED burn-in test FAQ

What is the difference between OLED burn-in and image retention?

Image retention is a temporary afterimage that can fade after the content changes or the display rests. Burn-in describes a persistent brightness or color difference caused by uneven pixel aging. Recheck the same location after normal content and the display's routine care cycle.

How long should I run this OLED burn-in test?

Two to five minutes is enough for a careful pass through low gray, primary colors, moving bars, and gradients. During continuous playback, this tool stops after five minutes and shows black until you choose to resume. The timer does not protect a paused static pattern; end the test yourself when you pause.

Should I set OLED brightness to 100 percent?

No. Start with the brightness and picture preset you use every day. Maximum brightness can exaggerate small differences and adds unnecessary panel stress without making the result more representative of normal use.

Should I test a new OLED monitor, TV, or phone?

A short pass during the return window can document dead pixels, tint, banding, and uniformity. Use normal brightness, inspect from the usual viewing position, and confirm anything suspicious in ordinary content before deciding what to do.

Can LCD screens show image retention?

Yes, some LCD panels can show temporary image persistence, although it is different from OLED pixel aging. The same solid colors and gray screens can help locate it, and the Backlight Bleed Test remains the better tool for bright LCD edges or corners.

When should I run Pixel Refresh or Panel Care?

Let the display complete its normal automatic maintenance first. If a visible afterimage remains in ordinary content, follow the instructions for your exact model before starting a manual refresh.

Why should I avoid repeating a manual panel refresh?

A deep manual refresh is a maintenance process, not a test pattern to run repeatedly. Some manufacturers warn that excessive manual refreshes can affect panel life. Use the automatic cycle normally and follow the model-specific support guide.

Does an OLED warranty cover burn-in?

Coverage varies by brand, model, country, usage type, and warranty plan. Save photos, note when the mark appears, keep the test conditions realistic, and check the written terms or contact the manufacturer while the return or warranty window is open.

What should I do if the same mark remains after testing?

Photograph it on several solid colors with locked camera exposure if possible, then recheck after normal moving content and the display's scheduled care cycle. If it remains visible during ordinary use, contact the seller or manufacturer with the model, usage history, and photos.
