How to test

  1. Move the window to the display you want to check. If checking HDR, enable it in the operating system and keep the display mode fixed.
  2. Select Detection to read the browser's dynamic-range and color-gamut reports. Note HDR capable, SDR reported, or Query unavailable.
  3. Switch to Dynamic range and inspect dark fields, white steps, and the small bright area. Then select Wide gamut and compare its color columns.
  4. Use the mode buttons or arrow keys; fullscreen is optional. Record the browser, display mode, and visible differences before exiting.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • Read the capability report and complete the visual checks. A useful visual reference is no unexpected merging of steps or distracting halo in the inspected fields.
  • There is no page-wide HDR pass score. SDR or an unavailable query is inconclusive for hardware health; a high capability signal does not confirm that HDR is currently enabled.

How to read your result

HDR capable / high dynamic range reported
The browser reports a high-dynamic-range capability signal. It does not confirm HDR is currently enabled, establish peak brightness, or certify the display.
SDR reported or Query unavailable
The current path does not report high dynamic range, or the query is unavailable. This alone does not establish a hardware fault.
Dark or bright steps merge; a bright patch has a halo
Contrast settings, tone mapping, or local dimming can affect these visual fields. The pattern is not a calibrated HDR luminance measurement.
Wide-gamut columns look identical
Browser support, the system profile, and display mapping may make them look alike. Identical columns do not prove a narrow-gamut panel.

These browser-drawn fields are not calibrated PQ or HLG HDR signals. The page cannot measure nits, native panel bit depth, contrast, HDR formats, or certification.

If you cannot get a result

  1. Check system HDR, the selected display, its preset, and the GPU output path. Reopen the page after changing the mode.
  2. Try another modern browser on the same display. An unavailable browser query is a compatibility result, not a failed panel.
  3. Keep brightness and room light steady for comparisons. Use a known HDR application for a second check of the actual HDR content path.

HDR test FAQ

Why does the test report SDR when my monitor supports HDR?

The browser sees the complete output path, not the monitor label alone. Enable HDR in the operating system, move the browser window to the HDR display, check the cable and GPU output, then reload. A capable display can still be reported as SDR when HDR is disabled or the browser cannot expose the signal.

Why does the Windows desktop look gray after HDR is enabled?

Most desktop pages are SDR and Windows must tone-map them inside an HDR output. That conversion can make SDR white, contrast, or color look different. Adjust the Windows SDR content brightness control and compare with HDR video or a game before judging the display.

Can a website measure my monitor's peak brightness in nits?

No. A webpage cannot turn what your eyes see into an accurate luminance measurement. Peak brightness, black level, contrast, and VESA DisplayHDR performance require a meter and controlled patterns. This tool only reports browser capability signals and shows visual checks.

Can this HDR test identify HDR10, HDR10+, or Dolby Vision?

No. The browser media query reports a high dynamic range environment, not the negotiated video format or display certification. HDR10, HDR10+, Dolby Vision, and HLG depend on the media, application, operating system, connection, and hardware chain.

Does a 24-bit browser color buffer mean my panel is not 10-bit?

No. The browser value commonly describes its RGB color buffer as 8 bits per channel, or 24 bits total. It does not reveal whether the physical panel is native 10-bit, 8-bit plus FRC, or how the GPU sends the final signal.

What should I look for on OLED and Mini LED displays?

On OLED, compare near-black separation and watch whether a large white area dims because of automatic brightness limiting. On Mini LED, inspect the small bright window for halos and check whether shadow detail changes when local dimming settings change.

Why do the sRGB and Display P3 color blocks look the same?

The display may be limited to sRGB, wide color may be disabled, or the browser and color profile may map both samples into a similar visible result. A visible difference is useful evidence, but no difference is not proof of a narrow-gamut panel.
