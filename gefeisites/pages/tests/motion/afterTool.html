How to test

  1. Use your everyday refresh rate and overdrive setting. Keep this window on the display you are checking.
  2. The target starts paused at 480 px/s. Select 240 px/s first, then choose Start target; entering fullscreen alone does not start motion.
  3. Follow the target with your eyes and inspect the trailing edge. Compare 480 and 960 px/s using the speed buttons while keeping the other settings fixed.
  4. If comparing overdrive modes, change one display setting at a time and repeat at the same speed. Choose Pause target before finishing.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • The moving edge has no obvious distracting dark smear or bright inverted halo. Some tracking blur can remain even on a working display.

How to read your result

A dark tail follows the target
Slow pixel transitions may cause smearing. Compare a different overdrive setting at the same speed.
A bright or inverted outline follows it
Overdrive may overshoot. A less aggressive response setting can make the edge cleaner.
The whole target jumps or pauses
Browser frame timing, system load, or refresh configuration may cause stutter. This differs from a trail behind an edge.

This is a visual comparison of motion behavior, not a measurement of response time in milliseconds, input lag, or hardware refresh rate.

If you cannot get a result

  1. If nothing moves, select a speed and Start target. A background tab or reduced-motion preference can leave motion paused.
  2. Close heavy tabs and apps, keep the page in the foreground, and check the system's selected refresh rate and power-saving mode.
  3. Repeat at 240 px/s before faster speeds. Compare the same display setting and speed so a change has a clear cause.

Frequently asked questions

What is the difference between ghosting and motion blur?

Ghosting is a visible trail caused mainly by pixels taking time to change. Motion blur can also include sample-and-hold blur from tracking a moving object with your eyes. A high refresh rate improves motion clarity, but slow pixel transitions can still leave dark or colored trails.

What is inverse ghosting or overdrive overshoot?

Inverse ghosting is a bright, dark, or inverted halo created when overdrive pushes pixels past the target value. It often appears after selecting an aggressive response-time mode. A lower overdrive setting may trade a little conventional ghosting for a cleaner trail.

Which overdrive setting should I use for this test?

Start with the setting you use every day, then compare the next lower and higher modes. Choose the fastest option that does not create distracting halos across your common refresh-rate range. The maximum setting is often tuned for a benchmark rather than the cleanest image.

Why does the motion test look choppy in my browser?

Confirm the operating system is using the intended refresh rate, close heavy tabs, keep the window on the test monitor, and disable battery-saving limits. Frame pacing from the browser or desktop can look like panel stutter, so repeat the test after reducing system load.

Can this page measure a monitor's response time in milliseconds?

No. It helps you compare visible trails and settings, but accurate response time requires a photodiode or high-speed capture with controlled transitions. Treat the page as a visual ghosting and motion blur test, not a laboratory response-time result.
