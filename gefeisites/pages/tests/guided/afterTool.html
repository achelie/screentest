How to test

  1. Clean the screen and use your everyday brightness. Choose Enter fullscreen, or press F, to inspect more of the panel.
  2. Use Next or the arrow keys to inspect all six scenes: white, black, RGB, gray, gradient, and motion. Check the center, edges, and corners.
  3. For each scene, select Looks normal, Noticed something, or Skip. At Motion, use Start target if it is paused and follow the moving target with your eyes.
  4. Recording an answer for the sixth scene opens the summary. Review every recorded answer; use the matching single test to check anything suspicious.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • All six scenes were actually inspected and marked Looks normal. You saw no fixed odd pixels, distracting patches, hard gradient bands, or obvious motion trails.
  • Skip and Not checked mean this pass is incomplete. They do not count as a normal result.

How to read your result

Nothing obvious showed up
You marked all six checks normal. This describes what you observed in this pass, not a complete hardware diagnosis.
This check is incomplete
At least one scene was skipped or left unchecked. Use Run again to inspect them before drawing an overall conclusion.
One or more checks need a closer look
The count is the number of scenes you marked suspicious. Review those scenes and any unfinished checks with their individual tools.

The browser displays patterns and summarizes your answers. It cannot see the panel, repair faults, or decide return and warranty eligibility. Answers stay in this page.

If you cannot get a result

  1. If motion is still, select Start target. Reduced-motion settings can leave it paused; a still target cannot check motion trails.
  2. If fullscreen is refused or unsupported, continue in the embedded panel or try the browser fullscreen command. Areas outside the panel remain unchecked.
  3. If a mark is hard to classify, clean the screen, repeat at your normal viewing angle, and open the matching single test. Use Run again for a fresh pass.

Frequently asked questions

Which tests should I run on a new monitor?

Start with solid colors for bad pixels, black for edge glow, gray for uniformity, gradients for banding, and motion for trails. Run the checks during the return window, then repeat anything suspicious using the brightness and viewing distance you use every day.

Should a monitor warm up before a screen test?

Yes. Give an LCD or OLED about 20 to 30 minutes if it has just been switched on. Near-black uniformity, brightness, and color can shift while the panel warms up. A quick first pass is still useful, but judge subtle issues after the display settles.

Can a screenshot prove that my monitor is faulty?

No. A screenshot records the rendered image, not the physical panel. View the screenshot on a second working display. If the mark travels with the screenshot, investigate software or the graphics pipeline. If it stays only on the original screen, inspect the panel.

Can an online monitor test replace professional measurement?

No. This screen test online is designed for visible defects and everyday comparisons. It cannot measure color accuracy, response time, luminance, or factory tolerance. Those checks need a colorimeter, high-speed camera, or controlled lab setup.
