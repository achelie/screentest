How to test

  1. Use a neutral display preset and turn off unusual contrast or color enhancements. Keep brightness and display mode fixed during the comparison.
  2. Enter fullscreen, select Neutral, and inspect both Horizontal and Vertical directions.
  3. Repeat with Red, Green, and Blue. Follow each ramp from its dark end to its light end and look for abrupt wide bands or blocks.
  4. Record the channel and direction of any break. Compare once in another browser, then exit fullscreen.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • Transitions look gradual in both directions, with no abrupt wide stripes, blocks, or sudden color jumps in the inspected channels.

How to read your result

A smooth ramp becomes hard stripes
The display path is introducing visible steps. The browser, output depth, processing, or panel may contribute.
Only one channel shows strong bands
A channel-specific setting or panel behavior may contribute. Compare the same channel in another browser.
Bands change after switching modes
The color profile, bit depth, output range, or display enhancement is influencing the gradient.

The page generates gradients without image compression, but the browser and display path still affect them. It does not certify panel bit depth or color accuracy.

If you cannot get a result

  1. Repeat in another modern browser with the same display settings to check whether rendering changes the bands.
  2. Inspect GPU color depth and output range, system color profile, and HDR/SDR mode. Change one setting at a time.
  3. Turn off aggressive contrast, black equalizer, or color enhancement and compare again. If only a video bands, also check its compression.

Frequently asked questions

What causes color banding in a smooth gradient?

Banding can come from limited bit depth, display processing, GPU output settings, color profiles, or the panel itself. Compression can also add steps to videos and images. This generated gradient removes image compression from the first check, but the rest of the display pipeline still matters.

How can I tell monitor banding from video compression?

Compare the problem content with this browser-generated gradient. If only one streamed video or compressed image shows bands, the source is the likely cause. If several clean gradients band in the same areas, inspect bit depth, color range, monitor settings, and the panel.

Will switching from 8-bit to 10-bit remove banding?

It can reduce steps when the operating system, GPU, connection, application, and panel all support the higher-bit path. It will not repair panel uniformity or poor processing. Confirm that the selected resolution and refresh rate still allow the intended color depth.

Why do the bands change after I adjust contrast or gamma?

Aggressive contrast, black equalizer, gamma, or enhancement settings can crush nearby shades or stretch too few values across a wider range. Resetting to a neutral preset is a useful comparison. Keep the settings that preserve smooth steps without hiding shadow detail.

Is a browser gradient banding test fully color-managed?

The browser, operating system, GPU, HDR mode, and monitor still influence the output. This page is useful for repeatable visual comparison, not a certified signal-generator measurement. Test another modern browser if one browser produces an unexpected result.
