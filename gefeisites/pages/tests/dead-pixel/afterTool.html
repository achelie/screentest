How to test

  1. Wipe away dust and use comfortable everyday brightness. Enter fullscreen with the button or F.
  2. Switch manually through white, black, red, green, and blue using the color buttons, Next, or arrow keys. Pause any automatic cycle while inspecting.
  3. Scan the center, all four corners, and edges on each background. Check whether a suspicious dot stays at the exact same position across colors.
  4. Record the position and backgrounds that reveal the dot. Exit fullscreen when you have inspected all five colors.

What counts as normal

Use these references for this visual check. They are not a manufacturer acceptance standard or a hardware certification.

  • No fixed dot stays dark, bright, or the wrong color across the backgrounds you inspected. A clean result applies only to the visible test area.

How to read your result

A dark dot on light backgrounds
A nonresponding pixel or subpixel is possible. Dust or surface damage can look similar, so clean first.
A bright or colored dot on black
A stuck pixel or subpixel is possible. Confirm that it remains fixed when the background changes.
The mark appears in a screenshot on another display
Investigate the app, source image, driver, or operating system. A physical panel fault is not captured in the screenshot itself.

This is a visual pixel check. It cannot automatically count defects, fix pixels, or apply the manufacturer's allowable-defect policy.

If you cannot get a result

  1. Clean gently and repeat the same colors; do not press or rub a suspected pixel.
  2. View a screenshot on a different working screen. A mark absent there is a clue toward this panel or its surface; it is not proof by itself.
  3. If browser controls cover an edge, hide controls with H or try browser fullscreen. Document any area that you could not inspect.

Frequently asked questions

How can I tell a dead pixel from a stuck pixel?

A dead pixel usually stays black on white, red, green, and blue screens. A stuck pixel keeps showing one color because one or more subpixels remain active. Check all five patterns before deciding. Dust can look identical, so clean the screen first.

What should I do if an OLED dead pixel test finds one bad pixel?

That depends on where the pixel sits, whether you notice it in normal use, the seller's return window, and the manufacturer's pixel policy. Test the whole OLED panel, save a photo, and check the written policy before the easy return period ends. One failed pixel does not automatically qualify every display for warranty replacement.

Can dead pixels spread across an OLED display?

One isolated failed pixel does not necessarily spread. A growing row, cluster, or dark edge can indicate a wider panel or connection fault. Photograph the same fullscreen color at intervals. If the affected area grows, stop treating it as a single-pixel problem and contact the manufacturer.

Can a pixel refresh or flashing video fix a dead pixel?

A true dead pixel usually cannot be revived by software. A stuck subpixel may change after normal use or a manufacturer-provided panel refresh, but rapid flashing tools are not guaranteed and can add unnecessary wear. Use the display maker's documented maintenance feature and avoid pressing or rubbing an OLED panel.

How do I run a dead pixel test on Android?

Open this page in Chrome on the Android phone, raise brightness to a comfortable level, tap Start Dead Pixel Test, and rotate through white, black, red, green, and blue. Inspect the camera cutout, rounded corners, and navigation-bar area. Browser fullscreen support varies, so hide browser controls if they remain visible.

Why does the suspicious dot disappear in a screenshot?

A screenshot records the image sent to the display, not the physical panel. If the dot is absent when that screenshot is viewed on another working screen, the panel is the likely source. If the dot appears in the screenshot elsewhere, investigate the app, image, graphics driver, or operating system instead.
