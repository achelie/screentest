# Finale deutsche Lokalisierung

Sprachen: Englisch nach Deutsch (`de-DE`)

Die veröffentlichungsreife Übersetzung befindet sich in den typisierten Produktionsdateien:

- `lib/i18n.ts`
- `lib/tests-copy.ts`
- `lib/test-messages.ts`
- `lib/state-messages.ts`

Verbindliche Terminologie:

| Englisch | Deutsch |
| --- | --- |
| dead pixel | Pixelfehler |
| backlight bleed | Backlight Bleeding |
| grayscale | Graustufen |
| uniformity | Gleichmäßigkeit |
| gradient banding | Banding in Farbverläufen |
| ghosting | Schlieren |
| overshoot | Überschwingen |

`ScreenTestHub` und sämtliche Slugs bleiben unverändert. Ratgeberartikel bleiben englisch und werden auf deutschen Übersichtsseiten als `Englischer Inhalt` gekennzeichnet.
